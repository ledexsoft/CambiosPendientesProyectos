# Cambios Pendientes Proyectos

Este repositorio está pensado como un espacio central para **anotar, organizar y analizar** cambios pendientes en mis proyectos.

## Objetivo

Tener una fuente de verdad simple para:
- Registrar tareas y mejoras pendientes.
- Priorizar cambios por impacto y urgencia.
- Dar seguimiento al estado de cada iniciativa.
- Mantener contexto técnico y decisiones clave.

## Proyecto principal actual

- **OneBlink**

## Estructura sugerida

Puedes usar esta base y adaptarla conforme crezca el proyecto:

- `pendientes/` → listas de cambios por proyecto.
- `analisis/` → notas de impacto, riesgos, dependencias y esfuerzo.
- `roadmap.md` → prioridades por semana/sprint.

## Formato recomendado para cada cambio

- **Título**: breve y claro.
- **Proyecto**: (ej. OneBlink).
- **Descripción**: qué se quiere cambiar y por qué.
- **Impacto**: alto / medio / bajo.
- **Esfuerzo estimado**: pequeño / mediano / grande.
- **Dependencias**: bloqueos o prerequisitos.
- **Estado**: pendiente / en progreso / hecho.
- **Fecha de registro** y **última actualización**.
